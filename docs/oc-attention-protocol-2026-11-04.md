# OC-A2：注意力改进执行协议

2026-11-04。用户明确授权在SVM之后继续注意力。四级编号挂在原检测头下；只改头内编码、汇总、结构或训练目标。所有以下配置在训练前封印，不凭测试成绩更改。

## 同一数据与信息边界

沿用OC-H3 OR训练300（两类各150），OC-H2正常校准400和历史OR测试1000正常/500危险；复用既有原F缓存及近重复审计，重查输入哈希和训练/目标的ID、规范化组、文本hash、完整输入hash互斥。固定14层原F，不加隐藏向量、词表坐标或读取位置。测试已被H2/H3/S1观察，本次全部为历史诊断，未独立确认。原文、逐条F、模型和逐条分数留校。

## 方案与直接对照

|方案|改动|直接对照／边界|
|---|---|---|
|OC-4-4-1|原查询式注意力汇总：共享1→16映射、层身份、2头查询汇总、线性输出|本轮按同训练程序重训并选择，作为主要机制基线|
|OC-4-4-2|原小Transformer：16宽、2头、1块、FFN32、同查询汇总|FT-Transformer直接基线|
|OC-4-2-1|原MLP：14→16→1、GELU|普通非线性参照|
|OC-4-4-1-1|门控汇总：softmax(wᵀ[tanh(Vz)×sigmoid(Uz)])后加权z|对原汇总；另对去掉sigmoid门的tanh汇总。门增加参数，不能视为严格等容量消融|
|ungated-pooling|相同tanh评分但无sigmoid乘法|门控消融，保留原F映射与层身份|
|OC-4-4-1-2|每层训练折分位点[0,.25,.5,.75,1]，4段PLE式编码，再共享4→16映射及原汇总|对原注意力；另对相同4维接口的线性编码注意力|
|linear-encoded-attention|把z重复4份并除以4，4→16映射、其余同PLE注意力|信息等价的线性编码，匹配显式参数形状；有效自由度仍不同|
|OC-4-2-1-1|同样PLE编码，展平56→16→1|对同56维接口线性编码MLP；与注意力编码收益做差中差|
|linear-encoded-mlp|重复z/4编码56→16→1|同接口MLP对照，另保留原14维MLP|
|OC-4-4-1-3|原OC-4-4-1结构，LibAUC pAUC_CVaR_Loss＋SOPA-adam|对BCE＋AdamW原汇总；损失、优化器、梯度裁剪与正则方式共同变化，不归因损失单项|
|OC-4-4-2-1|作者rtdl.FTTransformer.make_baseline，14独立数值映射、d_token16、1块、8头、FFN32、ReGLU、CLS汇总、零dropout|对原小Transformer与原汇总，整体架构迁移，不冒充单组件消融|

门控参考Ilse等ICML2018 Attention-based Deep Multiple Instance Learning，使用本项目小头迁移并保留层身份，不称作者整套多实例实验复现。PLE参考Gorishniy等NeurIPS2022 On Embeddings for Numerical Features in Tabular Deep Learning；本项目按公式实现4段编码，首末段线性外推、中间截断[0,1]。训练折内标准化与分位点拟合；若分位点重复则显式失败，不隐式减少段数。层身份不额外读取大模型信息，不能恢复F压缩丢掉的信息。

FT-Transformer采用官方发行包rtdl0.0.13，pAUC采用官方LibAUC1.4.0。包下载仅解压至任务隔离cache/vendor，不修改共享环境；下载归档SHA256对照PyPI元数据，运行使用的全部Python源码纳入封印。FT受控规模不代表作者默认大规模配置。

## 训练侧选择与训练程序

11种神经头各3学习率[.003,.001,.0003]×5折分层CV，折与S1相同seed20261104。选5折平均标准化pAUC最高者，≤1e-12平局按列表先后。每个拟合固定全批240次更新，不早停、不按测试调结构或选择种子。每折240训练/60验证；折内重新拟合标准化与分位点。验证每折正常只有30，低误报pAUC离散且选型不确定性较高。

BCE各头使用AdamW、weight_decay=.01。pAUC头使用pAUC_CVaR_Loss(beta=.1,eta=1,margin=1,surr_loss='squared_hinge')与SOPA(mode='adam',clip_value=1,weight_decay=.01,epoch_decay=0)，逐样本原始训练索引、pos_len真实计数，完整批同时包含两类。每一步检查损失、梯度与参数有限，保存最终逐正样本辅助状态，要求状态确实更新。LibAUC返回的训练数值是梯度代理，评估仍使用项目标准化pAUC，不将两者混同。

本轮全批240更新与H3原120epoch/256小批程序不同，因此主比较使用本轮重训基线，不将H3成绩直接当作结构作用。训练前附1次旧程序回归拟合，必须逐参数复现H3原注意力头，并在模型封印后核对旧逐样本分数与指标。

CV选型只用主种子；最终每头按20261104/20261105/20261106重训，165折内＋33最终＋1旧程序回归，共199次拟合。所有头宽度16，固定结构；报告真实参数量/耗时，不强称全部等容量。种子变化仅覆盖初始化，不覆盖数据抽样。所有模型先封印再读校准/测试F。

共同SVM参照使用已冻结OC-S1训练侧5折选择C=1的分数（同一训练300与同折），不再次依赖测试选型。神经头本轮各3候选，S1 SVM曾用9候选，跨家族比较预算并不完全相同，必须报告。

## 评估和15项预设主比较

全部风险分数高表示危险。每头以同400正常校准分数第381个为阈值，严格大于告警。目标5%不等于实际5%；不反调测试阈值。主要指标项目标准化pAUC(FPR≤.1)，并报AUROC、检出率/误报率及计数、所有种子、参数/耗时。

统一15项家族：

1. 门控−原注意力。
2. PLE注意力−原注意力。
3. PLE-MLP−同接口线性编码MLP。
4. pAUC训练注意力−原注意力。
5. FT−原小Transformer。
6. 门控−无门控。
7. PLE注意力−同接口线性编码注意力。
8. (PLE注意力−同接口线性注意力)−(PLE-MLP−同接口线性MLP)，检验编码收益是否对注意力额外有利。
9.～13. 五个四级候选分别−SVM。
14. FT−原注意力。
15. 原注意力−SVM。

主种子固定20261104，10000次标签分层配对bootstrap、seed20261104。全15项Bonferroni，每项双侧99.666667%主pAUC差区间。线性组合对每次相同重采样先计算再取区间。主差区间全正才称“本历史批支持改善”，含0写“未确认”。AUROC、冻结阈值检出率/误报率差95%区间仅描述性；区间以当前训练/选型、固定校准为条件，不覆盖其不确定性。对B额外报告同批点值，不另事后增加主假设。

评分后重载全部模型重算分数与计数；采用独立直方图ROC实现复算每模型每个bootstrap分布及15项全部区间。未通过不回填成功。失败日志与原冻结证据保留，数值修复须记录是否已经评分。结果接入同一棵导图、原头下的四级编号，只加粗改善后的数值。没有新数据时不自动将旧测试变成独立确认。
