# EI-PCA1：每层保留几个残差PCA方向？

用户指定新增EI-2-3-1、EI-2-3-2、EI-2-3-3，分别为每层1、2、8方向。原EI-2-3每层4方向保留，不改其冻结记录。

为只比较截断方向数，训练集每层一次拟合8方向PCA，各候选取前k方向；另训练同一基底的k=4匹配对照（K4）。旧4维随机化PCA与新8维PCA前4个方向可能略有差异，因此旧EI-2-3单列追溯，并重载复算其全部分数；不能把新K4改写为旧4维成绩。每层PCA均用原算法randomized、iterated_power=4、random_state=20261104，只fit训练集。

原14F、模型、norm/投影、模板末位、0基16～29层、训练1600/dev600/旧safe-cal400、C1000/RV1082/OR-cal400及OR-test1500都沿用已核验EI-V1，使用原私有Z/F缓存，不重新做模型前向。输入为14F＋14k残差方向，维数28、42、70、126，补零至512。

均值和标准差只fit训练集。F块除sqrt14；额外坐标统一除sqrt56（原k4的规则），不随k重新缩放，保证同一基底前若干坐标的尺度一致。k变化仍改变总输入能量和有效容量，不能把收益全解释成纯信息收益。

L2逻辑回归liblinear，max_iter5000，C=[0.1,1,10]，种子20261104/05/06；每臂按三种子dev AUROC均值选C，并列先取列表前项，不合并dev重训。四个PCA臂共36次拟合；另做三个14F＋同维独立高斯噪声控制（q=14/28/112），同样规则再27次，合计63次。噪声不用于选维数，种子由[20261105,k,全局行号]唯一确定，不接收标签/文本/ID。旧B-F及旧PCA4模型作为冻结参照重载，不额外选择其参数。

所有新头及训练变换封印后才访问校准/历史测试特征。旧safe400第381顺序统计量定阈值，严格大于告警；OR-safe400另列来源校准工作点。报告所有种子的AUROC、标准化pAUC(FPR≤0.1)、检出率、误报率及误报条数。

主比较为三新编号分别对本轮同基底K4，共享10000次按标签分层的配对bootstrap，各双侧98.333333%区间（尾概率0.05/6）。父级旧4维与B-F的点值另列追溯，不把基底变化混入主方向数结论。各历史批次分别分析，不声称跨批联合95%保证。若按dev提出候选，仍需未用来源确认；不得按测试成绩挑维数后称独立确认。

使用独立工作树和新结果目录，代码/协议先提交，缓存哈希对照EI-V1 verification.json后再使用。执行后另行重载PCA和检测头、重算全部分数、两套阈值、独立ROC点指标及全部区间，结果hash绑定后才回填原树的EI-2-3子分支。全部数据已被历史实验使用，本轮仅为历史诊断。
