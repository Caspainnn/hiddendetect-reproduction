# EI-IM1：EI-2-8五项真实图文信息实验执行协议

本协议在训练/验证模型选择及留出评分之前冻结。既有设计见[梳理表](ei2-image-information-design-2026-11-05.md)。不替换任何旧纯文本结果。

## 数据与任务口径

VLGuard官方文件当前gated，学校无授权缓存，本轮不接受账号分享条款或绕过访问控制。使用原方案已列出的公开MSSBench，官方revision `12396d24157427b671d97f23a2e370fca98fdf55`。753个官方文件含752张图片，图像逐一对照官方LFS SHA256，元数据对照Git blob，后续前向再次核对原图/输入哈希。

这是**情境安全介入检测**：1表示官方标注的图片情境需要安全提醒/介入，0为安全情境。它不等于图片内容审核、模型已被越狱，或所有1类请求均应拒答。不会把该结果当作原论文越狱检测完整复现或攻击成功率。没有使用官方unsafe_image/observation等参考描述作特征，用户输入仅来自queries/instruction。

原始场景、安全/危险图对、原始意图、相同字节/解码图片、pHash汉明距≤4的近重复图联合为连通组；同组不能跨角色。常见通用问题可在不同图像情境重复，不能将其本身作为单一意图分组或安全标签。聊天组按类别分层、固定三个随机种子依次切test、cal、dev，不查看模型分数。无官方训练划分，因此本轮自行冻结，不宣称官方split。

冻结实际预算（旧1600/600/400不够，按既有设计统一下调）：

## 冻结模型与读取

- 使用现有LLaVA-v1.6-Vicuna-7B、同一CLIP塔、FP16、llava_v1模板与原anyres预处理/分块合并，不改模型参数。按现有artifact-lock校验模型文件并核对实际加载的视觉权重；保存torch/transformers/Pillow/OCR版本。
- 读取原0基层16～29，即hidden_states[17:31]，完整输入末位。F_mm仍为原norm/词表投影与固定拒绝词参照余弦14F。真实图片占位展开后必须有视觉嵌入；排除图像换行token和padding，不允许默默截掉用户问题。展开后不得超过4096。
- 先在两条训练输入比较“原完整序列投影再取末位”和“仅末位投影”。差≤1e-7才使用等价优化，否则全轮统一回退完整序列投影。再核验标准images前向与显式准备视觉嵌入的F差≤1e-7。该规则不根据标签/测试表现选择。
- 为避免输出整张注意力矩阵改变后端或耗尽显存，通过只读q_proj hook与同次前向的已旋转KV，重建最后一行注意力；全部文本位置softmax、跨头平均，再只在有效视觉token内归一化。训练侧短序列与模型直接返回的注意力对照最大绝对差≤5e-4。hook不替换激活，原后端不变。
- 第一项V14使用视觉塔原anyres全图基础视图的576个patch均值（此视图无补边patch），单位化后训练侧PCA14；不把多个裁片的padding直接平均。

## 五项主臂与公共头

所有添加信息臂均为F_mm＋14个补充特征，28个有效输入。B-MM仅原14F_mm。原14F块与补充块各自训练标准化后除sqrt14，补零至512接口；B-T仅F_txt作辅助。L2 liblinear、max_iter5000、C=[0.1,1,10]、种子20261104/05/06。每臂9个头，按三种子平均dev AUROC选C，精确平局按网格先后；不重训dev，不按测试挑种子或重选C。

|正式编号|固定补充14维|
|---|---|
|EI-2-8-1|训练侧PCA14(单位化全图基础视图视觉均值)|
|EI-2-8-2|F_desc：OCR＋与问题相关的图片描述放入无图分支|
|EI-2-8-3|F_mm−F_txt；不再重复拼接F_txt|
|EI-2-8-4|每层按问题相关注意力池化的视觉状态，与train两类单位质心的余弦差C_roi14|
|EI-2-8-5|两轻微图像视图下各层F相对F_mm的最大绝对差：JPEG质量90、亮度0.95|

主训练臂B-MM、Noise14及五候选共63拟合。预登记七个诊断臂各9拟合：B-T、OCR-only、Caption-only、Neutral-description、ROI-uniform、ROI-random、Neutral-image-delta；合计126拟合、14个胜出方案×3种子＝42最终头。它们不参与五项主区间的判定。

- OCR固定用户目录Tesseract4.1.1、eng、psm11、单线程；依赖包与语言权重hash封存。失败不按标签丢样本，文字为空并登记。OCR文字截至256字符。
- 描述由同一个冻结LLaVA生成，只描述与问题有关的可见对象、动作与条件，明确不回答用户问题。固定do_sample=False、num_beams1、max_new_tokens40。生成模型不额外训练，不接触官方参考描述/标签。记录空描述、长度与来源hash，原文留缓存。
- F_desc/OCR-only/Caption-only共用冻结的文字数据模板。Neutral-description替换数据token为中性token，逐条保持相同数据token数、原问题、模板与总长度，控制提示及长度影响；这些无图分支的F都只作额外信息，F_mm不改。
- ROI-uniform与ROI-random只替换视觉池化权重，采用同样逐层质心流程；固定伪随机权重种子与视觉token数量，不含标签。区别于旧EI-2-7末位状态质心。
- 中性图为原图相同尺寸的RGB127图，控制图像位置/长度影响；该图只用于分支探测，不伪称另一条已知标签样本。有图/无图差不是图片的严格因果效应。
- 原图重复三次的数值/成本检查只在训练预检进行，不额外拟合一项全零控制头。每条原图的两个扰动视图同属原关联组，不新增标签样本。轻微变化仍可能影响OCR或场景理解，按任务/类别与原图质量报告，不假定不稳定就一定危险。

## 严格执行顺序

1. 校验公开文件、冻结清单/关联组/协议和代码；所有GPU预检仅用train。
2. 只提取train/dev的真实图片、视觉/文本分支与描述。保存逐条输入token、pixel_values、图像字节、描述/OCR哈希及视觉token数量；失败中断/归档，不删除困难测试样本凑分。
3. 只用train拟合PCA与三种视觉池化的类质心、标准化和126个头。选择后封存全部候选头、42最终条目、变换、搜索、训练/dev原始特征hash与完成索引。
4. 封印后才提取cal/test/task_test并评分。OCR和描述固定，不允许用模型评分或标签挑描述。模型不生成用户任务的回答，只有受限图片描述。

## 指标、统计与核验

- 主指标总体AUROC；同时报FPR≤10%的sklearn标准化pAUC、检出率、误报率与误报条数。82条正常cal取0基floor(0.95×82)=77号顺序统计量，严格score>阈值；校准粒度较粗须说明，不用测试补校准或调阈值。跨任务也用同一cal阈值，不拿跨任务正常测试重校准。
- 首种子20261104固定为主展示，全部三种子另报范围。主test五项候选分别对B-MM，10000次按关联组有放回配对bootstrap，五比较Bonferroni各99%区间（.005/.995分位），不按测试筛候选。跨任务只作描述性95%按组区间，4组的有限覆盖必须突出说明，不宣称外部泛化或多重检验确认。
- 诊断臂、类别/域子组仅描述；小子组无正负两类时不硬算AUROC/pAUC。模型延迟、显存、实际前向次数、缓存命中、OCR和生成耗时独立报告；不把多前向方法称单次前向同成本。
- 复核重新计算训练侧PCA/质心/标准化，重载126原头和42胜出条目绑定并复算dev选择，重放全部小分数/阈值/四指标与两批按组区间；另在冻结的训练和留出样本重载模型验证输入与原始特征/描述分支。只读审查一次，不根据测试回头改方案。
- 本轮只有一种真实公开数据源与一个基础模型，且情境安全标签不同于历史越狱标签。结论必须限制在此范围，不能搬来与旧C/RV/OR的AUROC跨批相减。

公开材料范围：自有脚本、样本ID/hash、角色与小分数、审计元数据和报告。不发布图片、OCR/描述原文、隐藏/视觉向量、基础模型、检测头或凭据。
