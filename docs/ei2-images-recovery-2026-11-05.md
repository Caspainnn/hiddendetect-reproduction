# EI-IM1恢复与成本记录补充

一次独立只读审查未发现确定的科学性阻断，但指出原run.py在出现留出checkpoint后不能重启，以及续跑会遗漏旧进程成本。冻结的训练/特征/核验源码保持原样，另加resume.py为恢复入口。

恢复时验证原源码、清单、训练特征与既有封印。已有封印时只加载原变换与检测头，不调用训练、不重选C；未封印时严禁存在留出特征。恢复使用原特征/头/统计函数，额外记录恢复源码hash及流程分支。

新恢复入口逐条保存累计计数、耗时及跨进程最大显存。旧checkpoint没有历史计数时不凭空还原：报告cost_complete=false，累计值为下界，不能当全轮精确成本。发生断电等非正常中断后，最后一条未保存操作也不能声称已完整计入。

未中断的原始单进程运行可以保留其完整原计数；完工成本审计会检查每个完成样本对应的一次原图、一次中性图、一次描述生成及两次扰动图调用，并明确恢复是否发生。独立的部署测时只用固定训练样本，不据测试选择或改模型。

test_resume.py验证“已有留出但已封印→重用原头”“未封印含留出→拒绝”“跨段成本相加且显存取最大”，契约先RED后GREEN。追加恢复代码没有改动原实验成绩或选择规则。
