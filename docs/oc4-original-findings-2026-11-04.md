# OC-O1：结果解释与同批对照

2026-11-04。用户明确指原OC-4的RV1082：原积分AUROC0.7565473145780051，正常300/危险782。此为项目Aegis历史批次，不是论文XSTest；本轮未扩大原论文多模态数据。原train1600/dev600/cal400全部复用，两组进阶版从头拟合。C1000仅补充。

主结论：八个进阶变式在RV上相对原积分的低误报pAUC差区间均为正，但不能据此说进阶模块都优于原检测头。原H1线性SVM pAUC0.703796、原注意力0.699331；新候选主种子最高分别为代价敏感SVM0.703459、分段编码注意力0.680486，没有形成对原H1最佳成品的点值领先。旧SVM/注意力仍应保留参照。

代价敏感SVM与RBF相对本轮新选型LinearSVC的pAUC改善获RV修正区间支持；但新LinearSVC因扩大后的9参数网格选择C0.001，RV pAUC降至0.667542，旧H1三参数网格的成品是0.703796。正差只支持本轮已选择系统间差异，不证明惩罚权重单项、更多调参或核方法普遍胜过原H1。RBF相对线性核SVC在RV亦获正差，C补充批次未重复。

全部五项神经改进相对本轮匹配直接对照的RV主区间均含零。OR上较好的pAUC注意力在此为0.670750，本轮原注意力0.670413，差仅+0.000337、修正区间[-0.021064,+0.021211]。OR的收益没有在原OC-4历史批次重复。

C1000补充显示收益不稳定：代价敏感/RBF对本轮SVM的低误报差区间均含零；分段编码注意力的pAUC为0.649263，低于本轮原注意力0.663474及同接口线性编码0.666926。其95%描述性区间不能当成RV主家族的独立确认。
