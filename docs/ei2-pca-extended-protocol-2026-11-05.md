# EI-PCA2：残差PCA补充16、32方向

用户指定补充每层16与32方向，正式编号EI-2-3-4、EI-2-3-5。原EI-V1与EI-PCA1冻结记录不覆盖。复用已核验EI-V1原14F/Z缓存，不重新前向。

沿用EI-PCA1：原14层（0基16～29）、模板末位、原F、训练1600/dev600/旧safe-cal400、历史C1000/RV1082/OR-cal400及test1500；L2逻辑回归liblinear，C=[.1,1,10]、max_iter5000、种子20261104/05/06。三种子dev AUROC均值选C，平局先取列表前项；不合并dev重训。主报告固定首种子。

每层一次训练侧拟合PCA32，randomized、iterated_power=4、random_state=20261104，取前4/8/16/32方向。新K4/K8为同基底对照；前次PCA8拟合的4/8分数另列追溯，并由执行器重载基底和头重现，不将新K8覆盖旧8。新拟合基底可能改变旧前几个方向，不能把跨基底差异全算方向数收益。

输入14F＋14k，原始维数70/126/238/462，均补零到512。标准化只fit训练；F块sqrt14、额外块统一sqrt56，与EI-PCA1一致，不随k改变前几坐标的缩放。总能量、秩与可变自由度随k变化，不能称等有效容量或纯信息归因。

四PCA臂×9＝36拟合；另有两个与16/32同维的14F＋独立高斯噪声控制，各9次，再18次，合计54。噪声随机流[20261105,k,全局行号]，不接收标签/文本/ID，不用于选方向数。方向、缩放和算法不因测试结果改变。

全部新头及变换封印后才投影校准/历史测试。旧safe400第381顺序统计量、严格大于告警；OR-safe400另列来源校准工作点。报告三种子的AUROC、标准化低误报pAUC(FPR≤.1)、检出率、误报率及误报条数。

主比较三项：16−同基底8、32−同基底8、32−16。每个历史批次共享10000次标签分层配对bootstrap，各双侧98.333333%区间（尾.05/6）。新K4与旧4/8以及噪声为描述性参照。各批分别分析，不声称跨批联合确认。所有数据均历史，不是独立新确认。

独立工作树configs/ei2-pca-extended及新结果目录，源/协议先提交；验证父封印与F/Z哈希。执行器重载前次旧4/8头复现分数；独立验证器重载本轮新18个所选头，检查训练预处理、选型/收敛、分数、两套阈值与四项指标，以另一加权秩算法复算全部9个主比较区间。独立验证器对旧参照做归档逐值核对，不额外声称第二次独立重载旧头。结果hash绑定后回填原树EI-2-3，不覆盖冻结记录。
