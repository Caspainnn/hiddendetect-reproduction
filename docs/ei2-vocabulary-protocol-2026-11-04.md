# EI-V1：原14F＋补充词表信息，匹配检测头验证

本协议执行用户批准的EI-2设计。冻结首轮四方案和两个完整端点；先完成首轮，再按资源逐项执行完整端点。模型、RV、norm/GEMM、末位、16..29层固定。不执行选层、位置或检测头结构搜索。

执行补充：服务器空闲内存约60 GiB，按1600×448014的float32输入约2.67 GiB估算，六方案可使用同一求解器顺序完成。完整端点与首轮均在查看评估成绩之前训练和封印，共108次拟合；若实际资源或收敛失败则如实停止该端点。不根据首轮测试表现决定是否执行完整端点。

数据：原OC-H1相同train1600/dev600/cal400/C1000/RV1082；原OC-H2的OR-cal400/OR-test1500仅作已观测来源诊断。全部评估数据均历史，不称独立新确认。样本及来源哈希在运行前保存，跨角色ID、文本hash及组须无交叉。Aegis已审计正常剩10条，OR-Bench亦已有确认及再训练消耗，不擅自把其剩余数据叫新测试；本轮不额外下载来源。

特征：所有方案显式保留原14F。①每层单位词表向量u的原拒绝坐标；②每层训练方差最大32个非拒绝坐标（同方差token ID升序）；③训练侧拟合u−F·r̂残差PCA，每层4维；④每层log(max(logits范数,1e-12))；⑤完整u；⑥完整原始logits。m取实际唯一拒绝token数。原词表投影与F在新提取8条训练样本上与OC-H1缓存比较，最大绝对差须≤1e-7，再提取/使用后续数据。raw-logits仅服务器私有cache保存float16，F保存原计算结果；u与范数用float64范数归一化后cast float32，变换差别照实登记。

标准化均只fit train，常数列scale1。F块除sqrt14，额外q维块除sqrtq。首轮及其控制补零到512（原始特征超过512则停止）；完整端点不压维，维数14+14V。补零不等于等有效容量，记录维数、矩阵秩、参数和成本。F复制控制用20次重复14F作为额外280维，仍为原信息；噪声按四个首轮方案的q分别生成，逐样本独立且与ID/文本/标签无关，固定候选次序和种子，不挑噪声赢家。

同一L2逻辑回归，liblinear，C=[0.1,1,10]，max_iter5000，class_weight=None，三种子20261104/05/06。3候选均以三个种子的dev AUROC均值选择，并列按列表先后；原F基线重训，不沿用OC-H1的pAUC赢家。不合并dev重训，不根据历史评估改坐标、PCA维数、缩放或C。首轮含B-F、4EI、Fcopy与4Noise，共90拟合；完整端点再18拟合。高维端点若不收敛或资源不足，记录失败，不换求解器后称同条件成功。模型/变换/选型封印后才读取cal与历史评估特征。

所有候选分别在旧safe400取第381顺序统计量、严格大于告警；OR-cal另给来源校准工作点。B-INT无本轮额外监督标签，单列原积分不作新增信息的主要归因对照。

主指标AUROC；同时报告标准化pAUC(FPR≤0.1)、TPR/FPR/误报条数、所有种子。固定首种子为主。每批共享10000次分层配对bootstrap，首轮4个EI对B-F各98.75%双侧百分位区间；完整端点家族2项（EI-2-5对B-F、EI-2-6对EI-2-5）各97.5%。控制比较描述性，不能据未调整的差值称确认性信息归因。由于全是历史评估，即使区间正，也只称本批历史诊断。新来源泛化和训练/选择/校准不确定性未覆盖。
