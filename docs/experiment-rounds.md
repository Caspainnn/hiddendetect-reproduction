# 按方法改动划分的实验轮次

2026-10-29按用户要求统一整理。此前“首轮／第二轮”有时指运行批次，有时指改进尝试，存在重叠。以后引用具体方法优先使用本表R编号。编号是对已有实验的事后方法分类，不表示新增实验、独立日期或事前注册了这些编号；历史报告标题和文件名保留。

边界：每个实质性改进思路单独编号；该思路内的单专家、位置消融、随机搜索、L1与logits等对照保留其对照身份，不自动称为优化成功。若后续改变检测头、选择方法、融合方式或阈值策略，也单独编号。

## 数据标记

- X：原方法本机XSTest450条；论文0.868仅作为论文报告参考，尚未完全对齐。
- A：F/C与PSO批次的Aegis主测试1000条。
- B：高维信息批次的Aegis主测试500条。
- C：最新融合批次的Aegis前瞻主测试1000条。
- D：最新融合批次的ToxicChat前瞻毒性辅助测试400条，不混作有害输入检测任务。

A/B/C不是同一批输入，不能直接用行间绝对AUROC计算优化增量。X与A/B/C的数据任务分布也不同；后续监督分类器使用1600条带标签训练输入，原积分规则没有相同的监督训练预算。

## 统一方法轮次

|编号|本次改变|数据与结果|可以得出的结论|
|---|---|---|---|
|R0 原方法复现|运行作者拒绝方向分数、固定区间积分与原选层|X：默认0.85828，自动选层0.85082；论文报告0.868|文本检测跑通，论文数值未完全对齐；不能称完整多模态复现|
|R1 监督F基线|不新增信号，先用标签学习32层F如何组合|A：0.83740；同批原固定积分0.77849|监督检测方案更强，但新增标签预算与检测头同时改变，不是纯新信号收益|
|R2 F＋C互补信号|增加每层“更接近正常还是危险训练质心”的C，形成64特征|A：F32为0.83740，全部F/C64为0.87402|同监督设置有信号增量；0.87402没有使用PSO选择|
|R3 F/C上的PSO选择|用BPSO搜索保留哪些特征组|A：五种子均值0.87075，等预算随机0.87078，全部64为0.87402|未证明PSO比随机或全部保留更好|
|R4 完整末位向量|直接使用32层最后输入位置完整隐藏向量＋ridge，131072维|B：0.92837；同批F/C64为0.89816|完整表示＋检测头构成更强方案；0.92837不使用PSO，也不是19270维统计特征的结果|
|R5 高维多信号拼接|引入多位置投影、轨迹、注意力及模块统计，候选19270维／259组，使用线性头|B：全部信息0.88154；同批末位完整向量0.92837、末位投影0.90730|更多信息直接拼接未超过强末位基线；不能把候选池规模当成最优方案实际输入|
|R6 高维特征交互|相同全部候选信息改用浅层树交互头|B：0.87840，线性全部信息0.88154|该交互头未证明有效；不排除其他交互形式|
|R7 高维分组PSO|在259组中用BPSO选择，再拟合检测头|B：线性五种子均值0.88303，等预算随机0.88035；树BPSO0.88195，随机0.87925|有小幅同任务搜索收益线索，但未超过强末位或简单稀疏对照，跨任务不稳定|
|R8 专家分数融合|四类信息各自训练专家，五折训练外分数学加性融合|C：强末位0.91576，四专家0.91920，增量区间[+0.00087,+0.00619]|同源主测试小幅排序提升；既定阈值召回65.6%降至64.6%，跨来源优势尚不稳定|
|R9 专家分数交互|在四分数上增加六个两两乘积|C：0.91952，对加性0.91920的差区间[-0.00078,+0.00150]|未证明交互项具有额外收益|
|R10 来源安全校准|模型不变，用独立同来源安全样本确定报警阈值|D：末位AUROC保持0.91070；召回30.0%升至55.5%，误报1.0%升至4.5%|改善过严迁移阈值下的召回，同时增加误报，不是AUROC提升，也无5%误报保证|

R4完整向量与F/C对照的比较同时改变了表示和估计器，可比较整体检测方案，但不能把全部收益归因于单一因素。高维提取运行时也保存了R4/R5/R6/R7所需信息；这些是同批比较中的不同方法变更，不是四次重新采集最终测试。

## 如何评价总体进步

方法确有提升，不能因PSO未胜出而否认信号和表示的价值；也不能把强基线的成绩归功于PSO。最新同一C测试、同一1600训练输入下，旧F/C64为0.88408，完整末位为0.91576，四专家为0.91920。这比将论文0.868、A上的0.87402、B上的0.92837和C上的0.91920连成曲线更可靠。

现有证据支持“监督内部信号方案变强、完整末位表示构成强基线、专家融合小幅改善同源排序”。尚未支持“PSO是主要收益来源、更多特征必然更好、交互头更强、跨来源稳定提升或实际低误报召回已经改善”。C上的新旧方案比较也不等于在原论文测试设置下超越0.868。
