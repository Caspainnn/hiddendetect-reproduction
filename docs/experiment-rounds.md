# 按方法改动划分的实验轮次

2026-10-29按用户要求统一整理。此前“首轮／第二轮”有时指运行批次，有时指改进尝试，存在重叠。以后引用具体方法优先使用本表R编号。编号是对已有实验的事后方法分类，不表示新增实验、独立日期或事前注册了这些编号；历史报告标题和文件名保留。

边界：每个实质性改进思路单独编号；该思路内的单专家、位置消融、随机搜索、L1与logits等对照保留其对照身份，不自动称为优化成功。若后续改变检测头、选择方法、融合方式或阈值策略，也单独编号。

## 数据标记

- X：原方法本机XSTest450条；论文0.868仅作为论文报告参考，尚未完全对齐。
- A：F/C与PSO批次的Aegis主测试1000条。
- B：高维信息批次的Aegis主测试500条。
- C：最新融合批次的Aegis前瞻主测试1000条。
- D：最新融合批次的ToxicChat前瞻毒性辅助测试400条，不混作有害输入检测任务。
- E：群体选择批次新取的Aegis确认400条，R14起作为历史补充。
- F：真实位置批次新取的Aegis确认1000条，排除全部12122个此前输入；同源训练分区留出，不是官方测试。
- G：逐层路由批次新取Aegis确认1000条，排除全部13122个旧输入及近重复；同源训练分区留出。
- H：用户加工批次新取Aegis确认1000条，排除全部14122个旧输入及近重复；与G不同，仍是同源确认。

A/B/C不是同一批输入，不能直接用行间绝对AUROC计算优化增量。X与A/B/C的数据任务分布也不同；后续监督分类器使用1600条带标签训练输入，原积分规则没有相同的监督训练预算。

R16—R18方案在新确认评分前注册，各候选先冻结提交。R18各搜索方法是新位置编码的匹配算法对照，未自动叫作优化成功。

R4完整向量与F/C对照的比较同时改变了表示和估计器，可比较整体检测方案，但不能把全部收益归因于单一因素。高维提取运行时也保存了R4/R5/R6/R7所需信息；这些是同批比较中的不同方法变更，不是四次重新采集最终测试。

## 如何评价总体进步

方法确有提升，不能因PSO未胜出而否认信号和表示的价值；也不能把强基线的成绩归功于PSO。最新同一C测试、同一1600训练输入下，旧F/C64为0.88408，完整末位为0.91576，四专家为0.91920。这比将论文0.868、A上的0.87402、B上的0.92837和C上的0.91920连成曲线更可靠。

现有证据支持“监督内部信号方案变强、完整末位表示构成强基线、专家融合小幅改善同源排序”。尚未支持“PSO是主要收益来源、更多特征必然更好、交互头更强、跨来源稳定提升或实际低误报召回已经改善”。C上的新旧方案比较也不等于在原论文测试设置下超越0.868。

历史证据：[原方法](../results/baseline-summary-2026-10-28.md)、[A批次](../results/signal-selection/report-2026-10-28.md)、[B批次](../results/highdim/report-2026-10-28.md)、[C/D批次](../results/fusion/report-2026-10-29.md)。

统一基准与新确认：[R11—R13报告](../results/swarm/report-2026-10-29.md)。这次把旧方案也放到同一比较集；旧八个头的22080个分数与上轮完全一致。新确认上四专家AUROC0.90030，B为0.90380，旧小幅收益未稳定复现，更新了证据范围。新400条评分后成为历史确认结果，不能在下一轮继续当作未见验证。

真实位置：[R14—R15报告](../results/positions/report-2026-10-29.md)。B权重完全未变，E上的0.90380与F上的0.92729是换确认样本的分数差，不是优化收益；固定C始终同一1000条。F评分后也成为历史确认数据。前缀对照中的微小信号存在执行形状数值解释，不作读取未来文本的证据。
