# EI-C1：EI-2-7-2 原14F＋对应质心C14

用户要求补充EI-2-7，使用与EI-PJ1相同数据集。沿用已登记的EI-2-7-2，不覆盖历史EI-2-7-1（F32＋C32）。EI-3-1-2仅C14不在本轮执行范围。

## 冻结设计

- 原EI-V1清单6582条，按原顺序与角色：train1600、dev600、cal400、C1000、RV1082、OR_cal400、OR_test1500。样本ID、文本与token哈希全部一致。全部测试已被历史实验使用，仅为历史诊断。
- 模型、模板末位不变，原14F对应0基16～29层，即output.hidden_states[17:31]。重新前向提取14×4096的FP16原隐藏状态，逐条重算14F，与EI-V1既有F逐项差≤1e-7才接受。原F输入始终使用既有精确缓存。
- 训练样本隐藏向量逐层单位化，按安全/危险类别分别取均值，再单位化为两个质心。C＝与危险质心的余弦−与安全质心的余弦，每层一个，共14个。质心仅使用train标签，train样本也使用该固定训练质心（包含自身的常规训练内变换）；不用dev/cal/test拟合。
- 三个同预算头：B-F仅14F；EI-2-7-2为14F＋C14；Noise为14F＋14维确定性高斯噪声（同维度描述性容量检查）。不额外执行仅C14，避免误报EI-3-1-2状态。
- 沿用EI-V1的pack：训练均值/标准差，F除sqrt14，补充块除sqrt14，补零至512接口。基线与候选同L2 liblinear、max_iter5000、C=[0.1,1,10]、种子[20261104,20261105,20261106]。各方案9次拟合，总27次。按三种子dev AUROC均值选C，精确平局按网格顺序。没有额外调参或重新分割。
- 训练/dev提取→训练质心、标准化、全部候选头→封存搜索与最终头→提取其余角色→评分。冻结后不按测试选择。
- 直接对照B-F，核验新拟合基线分数与EI-V1同角色基线复现差≤1e-7。Noise仅描述性。各批报AUROC、FPR≤10%标准化pAUC、检出率、误报率与条数；400条正常cal的第381顺序统计量，score严格大于阈值。OR再列OR_cal同规则重新校准，不重训。
- 唯一候选相对B-F，在三历史测试批各10000次分层配对bootstrap；三个AUROC比较Bonferroni，分别报98.333333%区间（尾部0.05/6），首种子主展示，三种子全部保留。历史多轮探索未被此校正覆盖，不称独立确认。
- 独立核验源码/清单/提取完成记录、F一致性、训练质心与标准化、27个原始头与9个最终条目绑定、dev选择、全部小分数与四指标/阈值、3个区间。训练权重、隐藏状态、原文与凭据不发布。
