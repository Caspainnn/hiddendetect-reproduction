# EI-PJ1 追加只读复核

独立审查发现原复核已检查全部588个头、选择规则、评分与区间，但没有逐项绑定最终模型中的30个检测头与验证集选出的原始试验文件。

追加 `audit_selected.py`：严格比较检测头类型、参数、系数、截距、类别、维度、迭代次数、标准化、方向坐标和种子，并重新计算每个最终头的验证集AUROC及均值。任何不一致均阻止发布。单元检查先确认缺少此检查时失败，再验证能拒绝同维度系数、标准化与坐标的篡改。

另从18份已封存的选择器派生逐层零权重比例，同时区分严格等于零与绝对值不超过1e-8的比例。不导出选择器权重。

原训练源码、协议、方向掩码、超参数、评分与原复核记录均保留。追加复核不训练、不重新选择，不改变结果。发布门槛为原复核与追加复核共同通过后的 `final-verification.json`。
