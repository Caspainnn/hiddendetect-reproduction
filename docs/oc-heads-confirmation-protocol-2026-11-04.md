# OC-H2：四固定方案的跨来源确认与稳健性

2026-11-04。用户批准开始下一轮探索。固定B原积分、OC-4-1-1逻辑回归、OC-4-1-3线性SVM、OC-4-4-1注意力汇总。第一阶段不重训、不调参；在全部新样本评分前冻结来源版本、去重后样本、模型和阈值。旧OC-H1运行与所有历史输入保留。

## 数据与来源边界

候选来源采用作者官方公开、无需额外访问申请的 `bench-llm/or-bench`（允许官方重定向到同一发布者更名后的地址）。数据卡许可CC-BY-4.0；获取前验证gated=false，固定仓库commit与文件SHA256。下载README、or-bench-80k.csv、or-bench-toxic.csv，只按原作者子集将80k映射正常0、toxic映射危险1。不读取或混入模型回答，不自行生成标签。另候选WildGuardMix需要访问申请，本轮不使用，不从镜像绕过限制。

OR-Bench针对过度拒绝，正常样本也可能包含敏感词，作者自动生成并筛选；它与原Aegis人工标注请求分布不同。新来源样本未在本项目评分，不等于基础模型预训练从未见过或标签语义完全一致；仅作该基准下的跨来源确认，不泛称普适安全提升。

按稳定哈希顺序预选最多5000条正常候选与全部toxic危险候选，再按原模板token长度≤512过滤，不截断。将全部已有records/probes、旧XSTest与原few-shot置于候选之前，合并进行NFKC/casefold/标点规范化及字符3～5gram TFIDF65536、cosine≥0.92连通分组，历史优先，每组仅保留一个。保留全审计于学校，仅导出计数与哈希摘要。不能声称去除了所有语义相近或同生成家族样本。

从可用正常中按冻结哈希顺序取前400作新来源正常校准，再取后1000作新测试正常；危险取前500，数量不足时全部保留。测试每类至少30、新校准至少400方可开始，实际可用数及子类分布评分前封印，不以旧样本填充。首次评分后的记录均转历史。

出处：Justin Cui、Wei-Lin Chiang、Ion Stoica、Cho-Jui Hsieh，OR-Bench: An Over-Refusal Benchmark for Large Language Models（2024）。数据：https://huggingface.co/datasets/bench-llm/or-bench；论文：https://arxiv.org/abs/2405.20947。保留作者、版本、许可与文件哈希，不在公开报告复制原文。

## 阶段一：冻结头的跨来源确认

使用学校OC-H1保存的三个已选定头，各保留原20261104/05/06种子对应权重；主结果仍为20261104。核对OC-H1 selection与pre-evaluation seal所记模型SHA，参数依旧为逻辑回归C0.1、线性SVM C10、注意力lr0.003（已经训练完成，不在新来源重训）。复用原14层F、原模板末位、原20-token参照与原norm/head投影精度；先用8个旧训练输入鲜提取32层F作精确身份核对。

主工作点沿用OC-H1旧400正常阈值，检验直接迁移；另单列使用新来源400正常校准的次要工作点，升序第381个、严格大于告警。新校准不能改变AUROC/pAUC排序，不能只因误报下降称排序提升。旧阈值与新阈值的结果完整保留。

主指标标准化pAUC(FPR≤0.1)，主种子。六个预设配对比较共一家族：LR对B、SVM对B、注意力对B、SVM对LR、注意力对LR、注意力对SVM。共享10000次标签分层配对bootstrap，seed20261104，分别双侧99.166667%差区间（6比较Bonferroni）。只有本来源对应主差区间全正才称该比较得到本轮新来源支持。另报AUROC及95%差区间、旧/新阈值下检出率/误报率与条数、Wilson95和95%率差区间；同时给三旧种子点值，不能挑种子或集成后替代主结果。

## 阶段二：训练与校准稳定性（独立于第一阶段选型）

第一阶段结果先封存，然后实施预设稳健性诊断，不用结果追加搜索。只复用OC-H1旧train1600与固定选定参数，5次分层有放回抽样，每次800正常+800危险，抽样/训练种子20261114～18。三学习头使用完全相同的每次训练索引，原训练标签池不变，不用新测试标签训练或早停。缩放只拟合各次重采样训练集，注意力依旧120epochs。总计15次拟合。新来源测试此时已观测，阶段二只称训练稳定性诊断；报告五次点值与最小/最大，不把五次均值当集成，也不把范围当置信区间。

另对阶段一固定主种子模型的旧400正常与新400正常校准分别做1000次有放回抽样，seed20261124；各次重算381阈值后，在同一已封存测试上报告检出/误报的经验2.5%～97.5%范围。这是固定测试条件下校准波动描述，不包含测试抽样和模型训练不确定性。四模型共用抽样索引。阶段二不替换阶段一的主模型或成功标准。

## 阶段三：机制研究的进入条件

只有注意力对两种线性头的额外价值都获得阶段一支持，并且在阶段二5次训练重采样中至少4次pAUC高于同次两种线性头，才进入下一轮动态权重、固定权重、等权等机制实验设计。该进入条件不等于机制已获证明。否则记录暂缓，优先解释跨来源失效或简单头优势，不在这批新测试上继续调结构。本轮不预先执行新增Transformer或层选择，层选择仍属EI。
