# 实验思维导图标准

用户确认日期：2026-11-02。适用于本项目后续实验思维导图的新增与维护，沿用当前已接受的形式与交互。

## 内容结构

所有方向接入项目原有的同一棵树。按照下面的思维链组织，体现为什么做某项实验，而非只列实验名称：

**宏观方向 → 具体问题（大白话） → 对应实验编号、名称 → 方法、结果。**

例如：OC → OC-3跨层汇总 → 强信号会不会被其他层稀释？ → OC-3-2最强4层平均 → 方法、结果、证据与结论。

- 保留已有EI、OC及其他方向，新增内容挂到正确父节点下。
- 方向、问题和实验各自成节点；方法、结果作为实验的子节点，证据与结论可另设子节点。
- 保持正式实验编号及追溯关系，不能因展示需要重新编号已冻结的实验。
- 方法用简短、具体的大白话，说明本次改了哪里及必要的对照条件。
- 结果提供同批基线与候选的“原来 → 现在”。涉及检测性能时保留AUROC、低误报pAUC、检出率、误报率，已有误报条数一并保留。
- 区分历史诊断、独立确认和待验证；未执行的实验明确写“待验证”，不填入其他输入范围或框架的旧结果。
- 不跨批相减或排名，不将数值上升自动解释为统计上确认改善；保留报告支持的结论与限制。

## 树状交互

- 横向树状布局，使用连线表达父子关系，延续当前简洁节点样式及EI、OC分支配色。
- 点击有子节点的节点，展开或收起其自身子分支；各级均可独立操作。
- 兄弟分支可以同时展开，不能通过替换右侧内容面板实现所谓“展开”。
- 收起父节点后再次展开，应保留其内部子节点原有的收放状态。
- 节点显示展开状态；收起时的圆圈数字表示直属子节点数。
- 保留“展开全部”“收起到方向”“恢复默认”，并支持键盘Enter切换、左右方向键收放。
- 默认展示适量层级和一条完整实验链路，避免首次进入时所有细节同时铺开。

## 全屏与画布操作

- 提供“全屏查看”和“退出全屏”，Esc可退出；全屏时画布占满可用窗口空间，操作栏保持可用。
- 浏览器原生全屏不可用时，仍能使用铺满窗口的查看方式。
- 全屏切换保留节点收放状态；退出后恢复页面滚动。
- 支持缩放按钮和比例显示，当前范围为40%～200%。
- 全屏下按住鼠标左键可拖动画布，包括从节点上开始拖动；拖动后松手不能误触节点收放。正常单击仍用于收放。
- 全屏下滚轮向上放大、向下缩小，以鼠标位置为缩放中心。
- 非全屏时保留页面原有滚轮滚动行为；支持画布横向、纵向滚动。

## 加粗规则

结果节点不能整段统一加粗。仅强调相对同批基线改善的候选数值：

|指标|加粗条件|
|---|---|
|AUROC、pAUC|候选数值高于基线|
|检出率／召回率／TPR|候选数值高于基线|
|误报率／FPR|候选数值低于基线|
|持平、变差、待验证|不加粗|

基线数值及普通说明保持正常字重。结构性标题可保留标题字重。加粗表示该指标的点值改善，不表示已通过独立验证或显著性检验。

## 维护入口与交付检查

用户实际访问的页面为 `experiments/detail.html?id=hiddendetect`，修改必须落实到此页面。

- 页面模板：`readings/论文阅读/网页/experiment-detail.html`。
- 导图界面与交互：同目录下的 `experiment-mindmap.html`、`experiment-mindmap.css`、`experiment-mindmap.js`。
- OC内容及结果读取：同目录下的 `experiment_mindmap.py`；OC-3/4问题链来自 `experiments/HiddenDetect/research-map.md`，指标来自归档结果JSON。
- 生成流程：`build_experiments.py`；运行 `python readings/论文阅读/网页/hub.py` 重建实际页面，确保后续重建不覆盖更新。
- 不以只改Markdown、总览页或另加一个独立展示区域作为完成。
- 内容检查：编号、父子关系、同批数据、待验证标记及条件加粗正确；已有方向保留。
- 交互检查：逐级收放、状态保留、全屏进入退出、拖动不误触、滚轮缩放与按钮缩放可用；修改相关行为时执行相应检查。
- 浏览器实测与脚本逻辑检查应如实区分，不能把逻辑检查表述为已实际查看页面。
