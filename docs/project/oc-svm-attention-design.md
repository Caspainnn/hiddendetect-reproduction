## 共同执行约束

- 固定原模型、模板、拒绝词、真实末位、0基闭区间[16,29]的14个F，不增加隐藏向量、词表坐标或读取位置。层身份和F的确定性编码属于头内处理，不增加大模型信息。
- 主线拟复用H3同来源训练框架：OR训练300、正常校准400、历史测试1000正常加500危险。先查远端缓存身份和交叉污染，冻结清单后才使用。旧来源训练和历史C/RV作为次要迁移诊断，不能冒充独立新确认。
- 超参数只在训练侧分层交叉验证选择。预处理、分段点均在各训练折内拟合；校准和测试不参与选择。候选网格、折数、种子、步数与预算在训练前写执行协议并封印，不凭测试调结构、调权重或翻转分数。
- 所有学习头在同一训练和评估框架下重训。不能把H1的1600条旧源头当作300条新源候选的唯一对照。保留H3旧头仅作历史参照。
- 校准沿用400正常分数升序第381个、严格大于告警。目标5%不等于测试实际5%。每个头单独校准，但使用同一校准记录。
- 主指标为项目既有标准化pAUC（FPR≤0.1），另报AUROC、检出率、误报率与误报条数、参数量及耗时。训练用代理目标不等于评估实现。
- 在评分前固定各阶段的比较家族、配对bootstrap和多重比较规则；主种子及其他种子全部报告。区间含0写“改善未确认”，不写等价或完全无效。
- 所有已看过测试只用于历史诊断。独立确认需另审计未使用的数据来源或批次，冻结后首次评分。若数据不足，明确报告，不以旧批次充新。
- 结果节点保留同批“基线→候选”的四项指标；只加粗改善后的数值，待验证节点不填写成绩。

## 实现依据与迁移边界

本表沿用本对话前两轮已核验的论文候选，不表示相应代码已在项目安装或验证。

|方向|依据／实现线索|执行前核对|
|---|---|---|
|类别加权与RBF|scikit-learn LinearSVC、SVC|锁版本、损失与求解器；线性核SVC辅助对照|
|pAUC-SVM|Narasimhan、Agarwal，ICML 2013，A Structural SVM Based Approach for Optimizing Partial AUC|核对原文目标区间与可用实现；不将LibAUC代理目标冒称原论文精确复现|
|门控汇总|Ilse等，ICML 2018，Attention-based Deep Multiple Instance Learning；作者AttentionDeepMIL|迁移到层序列时保留层身份；同时保留无门控消融|
|数值编码|Gorishniy等，NeurIPS 2022，On Embeddings for Numerical Features in Tabular Deep Learning；rtdl-num-embeddings|训练折内分段点与维度；注意力和MLP用相同编码|
|pAUC注意力|Zhu等，ICML 2022，When AUC meets DRO；LibAUC|核对pAUC_CVaR_Loss及配套优化器，不能只换损失而遗漏状态更新|
|FT-Transformer|Gorishniy等，NeurIPS 2021，Revisiting Deep Learning Models for Tabular Data；rtdl-revisiting-models|控制宽度、层数和预算，整体迁移不冒充单模块因果结论|
