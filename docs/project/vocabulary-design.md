## 归属与旧编号

归入现有 **EI-2词表信息保留**，细化为EI-2-1～EI-2-6，不另立一级方向。原EI-2“完整下一token logits”是本问题的完整信息端点；现在补齐从F到更多词表信息之间的对照链。原来的历史完整logits记录及其运行编号保持原样，不倒填到新增编号。

统一追溯名称：**旧OC-4-3／迁入EI**。“旧”指保留更多词表特征的方案；当前OC-4-3是树模型类。旧方案迁入整个EI-2问题族，不把旧编号硬映射为其中唯一一个新子实验。当前OC-4八头的14F结果不能作为本方向的结果。

判断归属看检测头实际拿到了什么：相同14个F换检测头属于OC-4；相对于14F增加词表坐标、方向或幅度属于EI-2，即使均来自同一次前向。复制F、对F做高维嵌入或多项式展开仍是同一信息，只能作表达/容量对照，不能宣称恢复词表信息。

## 原方法在哪一步丢信息

原输入模板末位、每层隐藏状态 → 沿用作者norm和完整词表投影 → 完整logits向量z → 与固定拒绝参照r作余弦 → 每层一个F → 只取0基[16,29]的14个F → 固定汇总或检测头。

设u=z/||z||，参照单位方向r̂=r/||r||，则概念上F=u·r̂。一个F保留了沿拒绝方向的投影，丢掉了“具体哪些词高/低”、拒绝方向之外的结构及整体logits幅度。逐词坐标指词表token ID，不把多token字符串当成单个词；实际唯一拒绝坐标数m由冻结的原tokenizer和RV确定并记录，不能只照抄字符串数量。

下面的投影公式用于解释信息边界；实现时必须保留原norm、GEMM形状、精度及末层重复norm等原行为，并重新核验F缓存等价性，不能因为换了高效实现就默认同分。

## 共同条件与对照

### 首轮拟议固定设置

- 原模型、checkpoint、tokenizer、模板、RV、完整投影方式、精度和模板末位均固定；只读取0基[16,29]的14层。不得同时用选层实验[9,19]，也不换倒数第二token。
- 统一采用L2逻辑回归，不根据OC-4历史测试成绩挑检测头。拟沿用liblinear、max_iter=5000、C∈{0.1,1,10}，每组3候选×3预定种子。种子固定20261104/05/06，主报告固定首种子；不能按测试结果挑种子。
- 首轮B-F及EI-2-1～4均组织为512维输入：原F通道＋额外通道＋末尾补零。补零只统一接口，不算增加信息。m与实际维数核查后若超过512，须在任何评分前改协议并同步全部首轮方案。
- 各坐标的均值、标准差仅拟合训练样本，常数列用scale=1；随后固定原F块按1/√14、额外块按1/√q缩放，q为该候选实际额外坐标数，最后补零。不得按测试效果选是否标准化或块权重。
- 512维接口相同不等于有效容量相同：基线只有14个可变输入，候选有更多非零自由方向。报告原始维数、压缩后维数、有效秩、非零通道数、参数及成本，不能仅凭头结构相同就把收益全解释为纯信息收益。
- 原标签预算建议复用同一训练1600条（800/类）、选择600条（300/类）、独立安全校准400条；这是本方案拟议预算，执行前核对角色、组和来源并封印。OC-H1已用过的C/RV及新来源确认数据一律按当时最新使用历史审计，不再冒充未见测试。
- 保留用户“总体AUROC优先”的目标：用三个种子的选择集AUROC均值在3个C中选型，并列取固定列表首项；pAUC、固定阈值检出率/误报率及误报条数作补充。OC-H1按pAUC选型，故其已选模型不可直接拿来当本轮B-F；本轮同规则重训。
- 校准不参与特征或参数选择。拟沿用safe400第381顺序统计量、严格大于告警，所有候选各自冻结阈值；不在测试集反调到恰好5%误报。

### 必备比较，避免把不同因素混在一起

|标识|输入与用途|如何使用|状态|
|---|---|---|---|

|B-F|14F＋本轮同一逻辑回归，补零至512|所有首轮EI主对照；预处理、标签和3×3选择预算相同|待验证|

|CTRL-noise-j|14F＋与第j个首轮候选同维的独立随机噪声|每行噪声独立生成、与标签/文本/ID/来源独立，固定随机种子，仅训练侧拟合缩放；j=1～4分别匹配，检查额外维数是否只是带来容量或偶然性|待验证，诊断控制|

首轮5个主臂（B-F＋4个EI）共45次拟合；F复制控制1臂与4个同维噪声控制再45次，共拟议90次。另报B-INT，全部失败/退化和所有种子保留。相同拟合次数不等于相同训练时间，报告实际成本。

扩展轮EI-2-5/6不能塞入512维后仍称“完整词表”。两者必须使用14＋14V维，改变了输入规模、有效参数和优化成本；仅保持头家族与标签/选型次数一致，不宣称完全等容量。若需更换求解器、降低精度或调整迭代上限，先建立配套B-F重跑并把变更列为额外因素，不能与首轮直接混算收益。预算不足时记“资源未达／未执行”，不以压缩版替代完整端点。

## 训练侧变换与验证门槛

1. 先以完整历史、近重复组和来源审计确定train/selection/cal/test。训练折内拟合所有坐标选择、PCA、中心、标准化；交叉验证时每折重拟合，不能先在全数据PCA后再切分。选择集只选已列出的C，不另试k、PCA维数、层、位置、坐标策略或随机种子。
2. 固定m、k=32、PCA=4、层列表、词表坐标列表、PCA方向、随机种子与变换哈希。PCA必要的实现随机性固定，不能在测试挑变换。训练均值/方差和模型一起封印；除非明确另立重训协议，不选型后合并dev重新拟合。
3. 在任何新评估前核对原F逐值或预定容差等价性、角色隔离和变换应用；保留输入特征的来源、维数与hash。只留小分数或按资源方案缓存，不能把隐藏状态、原logits和私有提示词带到公开仓库。
4. 新确认必须先证明有足够未使用数据。目前历史记录已有“正常样本仅余10条”的警告，不能用旧数据补齐；先审计更新后的所有历史，落实新来源/新批次并在评分前定样本量。没有新数据，只能报告历史诊断，不能写验证成功。
5. 首轮预设4个主比较EI-2-1～4各对B-F，建议共享10000次分层、组安全的配对bootstrap，每项双侧98.75%区间近似控制4项家族95%；只有每组1代表时才按行重采样。固定选择/训练/校准后的区间不覆盖这些阶段的抽样不确定性。噪声/复制及B-INT比较为诊断，不事后改为主检验；若要据其作确认性信息归因，须评分前扩大家族并重新分配检验预算。
6. 全部报告AUROC、标准化pAUC(FPR≤0.1)、冻结阈值检出率、误报率、误报条数、成本及种子波动。扩展轮另行冻结比较家族和独立确认数据，不重用首轮测试反复择优。

## 设计时的结果边界（后续EI-V1另行执行）

当前新增六项全部待验证，没有“14F输入 versus 更多词表信息”的严格匹配直接对照成绩。历史EI-2完整logits实验仅保留原框架、层范围、检测头及数据追溯；0.83740→0.87822不能移作本计划结果。OC-4各头始终输入14F，其历史/新确认只能证明各自固定输入下的检测头表现，也不能作为EI-2验证。

本轮结论只涉及归属和设计：旧方案是已有EI-2的细化；值得分别判断“具体拒绝坐标、参照外坐标、残差信息、幅度、完整端点”。是否提高性能，必须等匹配对照验证后再判断。本设计文件本身不触发实验执行。后续已按用户明确授权完成EI-V1；这里的“待验证”是最初设计时状态，当前状态见顶部执行说明与核验报告。
