## 逐问题解释

### OC-4-1-3-1：更重罚误拦正常输入能否改善低误报表现？

改动：类别加权，其他LinearSVC结构不变；超参数均在训练侧重新选择。同批调参线性SVM → 候选：AUROC 0.960786 → 0.957296；pAUC 0.861074 → 0.858411；检出率 77.00% → 77.40%；误报率 4.30% → 4.80%（43 → 48条）。主差区间[-0.010484, +0.004679]，改善未确认。

### OC-4-1-3-2：两类之间需要弯曲的边界吗？

改动：RBF核，并保留线性核SVC对照；与LinearSVC还有损失/求解器差异。同批调参线性SVM → 候选：AUROC 0.960786 → 0.955268；pAUC 0.861074 → 0.829926；检出率 77.00% → 73.40%；误报率 4.30% → 3.80%（43 → 38条）。主差区间[-0.055937, -0.009016]，本历史批支持下降。

### OC-4-1-3-3：直接关注低误报区间能否改善线性排序？

改动：top-negative成对hinge代理目标与cutting-plane求解器，不增加输入信息。同批调参线性SVM → 候选：AUROC 0.960786 → 0.954030；pAUC 0.861074 → 0.856821；检出率 77.00% → 77.20%；误报率 4.30% → 4.30%（43 → 43条）。主差区间[-0.014384, +0.005700]，改善未确认。

代价头固定C消融：正常权重1 → 所选权重4，pAUC 0.848842 → 0.858411；检出率 77.00% → 77.40%；误报率 5.10% → 4.80%。仅点值描述，不另称校正显著。

## 实现与复核

pAUC方案是本项目的论文思路迁移，不是作者求解器精确复现。48个pAUC拟合均通过收敛检查，最大oracle间隙9.49878421e-08，最大primal-dual gap9.66425063e-05。自检包含枚举负样本子集oracle、有限差分子梯度、r=1与基线一致性、QP证书及模型重载。
H3固定C10逐样本分数、AUROC0.959700、pAUC0.857305和382检出/40误报复现通过。17个模型重载，24组指标与阈值/计数复核，80000次独立直方图ROC复算，四组全部区间复核通过。原H3清单与输入hash封印、训练与校准/测试ID/规范化组/文本及输入hash互斥检查通过；复用已有近重复排除证据。

## 证据与限制

- 主种子20261104，10000次标签分层配对bootstrap，四比较Bonferroni校正。阈值为400正常最终分数第381顺序统计量、严格大于告警；实际误报率并不被固定为5%。
- 所有测试均已观察。仅同一OR-Bench任务的300条训练数据，标签来自公开基准；不能扩大为真实部署或跨领域结论。
- 本轮没有额外训练抽样、校准不确定性或嵌套CV置信区间。pAUC模型仅beta=0.1；不自动推广到其他误报区间。
- 结构和参数没有按本轮测试成绩追加搜索。失败或未确认项保留；注意力实验待单独执行。
