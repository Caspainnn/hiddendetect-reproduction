# EI-PS1：自动筛选具体方向

本轮验证现行EI-2-3-3三个候选：L1、Elastic Net、分类ARD。问题是：每层32个方向中，有些是否没用；跳着挑选能否比全部保留、或只留同样数量的前几个方向更准？

结论：能减少输入方向，但本轮没有证明相对全部32方向提高总体AUROC。L1保留222/448、Elastic Net保留336/448，表现接近全部保留；ARD只留37/448，压缩明显，但外层更新到100轮仍未达固定点。历史C/RV/OR都已被观察，本轮是历史诊断，不能当作独立泛化确认。

## 怎么做的

固定0基16～29层、原模板末位、原14F、训练侧PCA32、1600训练标签、600选择标签、最终L2逻辑回归和C=[0.1,1,10]。只对新增448个PCA坐标筛选，原14F始终留下；筛选后丢掉临时分类头，重训原L2头。标准化只fit训练侧；F除sqrt14，所有额外坐标均除sqrt56，补零512，避免随筛选数量改变块权重。

各方法预先冻结3个mask参数候选，再比较3个C、3个头种子。按dev平均AUROC决定参数，不看测试挑赢家。选择器本身是确定性的，三个头seed不代表三次独立方向选择。L1/EN只对PCA施加稀疏惩罚；ARD使用二分类Laplace后验，不使用回归ARD。

另设“同数量前几个”对照：逐层数量与筛选结果相同，使用同C和同头，只替换方向位置。该对照沿用候选选出的数量/C，不是单独调参的前缀冠军。相对固定32多了额外选择预算，不能将差异全归于信息范围。

## 大白话解读

- L1：约去掉一半方向，C/RV/OR的AUROC和全部32很接近。C上比同数量前缀更好，OR上却更差，说明训练侧挑出的坐标未必适合来源变化。
- Elastic Net：留下四分之三方向，效果也基本接近全部保留。不能仅凭其保留更多、重合率更高就说筛选一定更稳定或更准。
- ARD：只留下37个方向，在C/RV比同数量前缀有区间支持的提升，说明少量方向时“选哪些”确实可能重要；但没有证明胜过全部32，在OR也未确认胜过同数量前缀。100轮外层更新未收敛，当前只是有上限的近似实现。
- 当前不能用本轮选出跨来源通用的最优方案。若目标优先总体AUROC，可将L1作为压缩候选进一步验证；正式替换需冻结选择规则，再用未使用来源确认。
